# SQLマスターへの道 Ver4 完成版

GitHub Pages向けの静的Webアプリです。ビルド不要です。

## 実装済み
- 初級10・中級10・上級10ユニット
- 各UNIT 5ステップ
- XP、レベル1-100、称号
- 中級: 初級ボス撃破 + 1000XP
- 上級: 中級ボス撃破 + 3000XP
- デイリークエスト
- 初級・中級・上級ボス
- 30スキルのスキルツリー
- 実績・称号
- localStorage保存
- スマホ対応

## GitHub Pages公開
1. ZIPを展開
2. index.html / style.css / data.js / app.js / README.md をリポジトリ直下へアップロード
3. Commit changes
4. Settings > Pages > Deploy from a branch > main / (root)
5. 公開URLを再読み込み

## 注意
SQLは実DBでは実行せず、正規化した模範解答との照合です。
