1. 教育

今回理解する操作：処理を複数段階に分ける

業務上の依頼：整形と集計を分ける

WITH base AS (SELECT * FROM patients), summary AS (SELECT ward,COUNT(*) cnt FROM base GROUP BY ward) SELECT * FROM summary;

構文の記号や単語を当てるのではなく、処理前と処理後でデータがどう変わるかを理解します。

2. 例題 1問

依頼：整形と集計を分ける

  2. 対象テーブルを確認する
  3. 必要なデータ操作を判断する
  4. 結果を予測してからSQLを見る
例題の解答と解説
WITH base AS (SELECT * FROM patients), summary AS (SELECT ward,COUNT(*) cnt FROM base GROUP BY ward) SELECT * FROM summary;
